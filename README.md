# Executive Dashboard — Demo

A visual demo of an executive management dashboard: overview KPIs, finance
(P&L, cash flow, balance sheet), sales, stock and analytics.

- **Demo only — all figures are invented sample data.** Amounts are in
  million UZS; the sample period is April–September 2026.
- **Single file, no build step.** Everything (CSS, JavaScript, SVG charts) is
  inline in `index.html`. No frameworks, no external libraries, no network
  requests.
- **Works anywhere.** Open `index.html` directly in a browser, or drop it on
  any static host (GitHub Pages, Netlify, S3, nginx…).
- Light and dark mode, responsive: sidebar navigation on desktop, bottom tab
  bar on phones.
